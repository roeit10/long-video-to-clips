# מסרטון ארוך לקטעים קצרים - סקיל לקלוד קוד

סקיל שלוקח סרטון ארוך שצילמתם (הדרכה, לייב, פודקאסט) ומוציא ממנו 3-5 קטעים אנכיים, מוכנים לפרסום:
- טבלה מדורגת של הרגעים הכי חזקים, עם נימוק לכל אחד, ומה נפסל ולמה
- כל קטע חתוך ל-9:16, בלי שתיקות, בעוצמה של הרשתות
- הוק על המסך בשלוש השניות הראשונות
- כתוביות בעברית לאורך כל הקטע, צרובות בווידאו: גדולות וקריאות, מעל אזור הממשק של אינסטגרם, עם תיקון המילים שהתמלול שיבש
- טקסט לפוסט ליד כל קטע, ולוח פרסום עם סדר מומלץ

הכל רץ על המחשב שלכם: תמלול עברי עם ivrit.ai, ffmpeg ו-Pillow לכתוביות (עובד גם כשב-ffmpeg אין תמיכה בכתוביות). בלי מנוי לכלי חיתוך.

## התקנה ושימוש
1. פותחים קלוד קוד על התיקייה שבה הסרטון.
2. מדביקים את הלינק לריפו הזה וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**.
3. כותבים: **"תהפוך את הסרטון בתיקייה לקטעים קצרים"**.
4. בוחרים מספרים מהטבלה, למשל **"תחתוך 1, 2, 3"**.

הקטעים מחכים בתיקייה `clips/`.

## מה הסקיל לא עושה
- לא מוסיף זומים, אפקטים או מוזיקה (לזה יש סקיל עריכת רילס נפרד).
- לא מפרסם לרשתות.
